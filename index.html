LMCServer 客户端

Luozaixuan MCServer · PCL 启动器远程主页

当前整合包版本 v1.7 · 2026-07-31

1在 PCL 中设置本主页

  1. 打开 PCL 启动器（2.8.1 及以上版本）
  2. 依次点击 设置 → 个性化 → 自定义主页 → 联网更新
  3. 在“下载地址”中填入：
    https://lmcs-pclhomepage.pages.dev/Custom.xaml
  4. 返回启动页，主页加载完成 ✓

提示：PCL 会自动检查 Custom.xaml.ini 中的版本号，主页更新后会自动刷新缓存。

2安装 LMCServer 客户端（首次）

在主页上点击 「① 下载 LMCServer 整合包」，文件会自动保存到当前 .minecraft 文件夹；
再点击 「② 导入并安装整合包」，选择刚下载的 LMCServer.zip，实例名填写 LMCServer 即可。

直接下载 LMCServer.zip (v1.7)

3更新 LMCServer 整合包

在启动页左侧选中 LMCServer 实例后，回到主页点击 「① 下载最新整合包」，再点击 「② 安装到已有 LMCServer 实例」；
导入安装时实例名保持为 LMCServer，PCL 会自动覆盖更新该实例的文件，世界存档与玩家数据不会丢失。

⚠ 更新前请确认主页上显示的“当前选中实例”为 LMCServer。
